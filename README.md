# Superstore Sales Analysis (2014–2017)

Анализ продаж крупного супермаркета США: поиск проблемных категорий,
регионов и подкатегорий, оценка динамики и сезонности, бизнес-рекомендации.

**Стек:** Python (pandas, matplotlib, seaborn), SQL (SQLite).
**Данные:** [Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final) —
9994 строки, 21 колонка, период 2014–2017.

---

## О проекте

Датасет содержит историю заказов супермаркета за 4 года: даты заказа и
отгрузки, клиента и сегмент, регион, категорию и подкатегорию товара,
выручку, количество, скидку и прибыль.

**Цель анализа:**
- найти проблемные категории, регионы и подкатегории;
- понять, чем вызваны убытки (скидки? структура ассортимента?);
- оценить динамику и сезонность;
- сформулировать конкретные бизнес-рекомендации.

Работа ведётся в Jupyter Notebook: данные загружаются через pandas,
сохраняются в SQLite, все агрегаты считаются SQL-запросами,
визуализация — matplotlib и seaborn.

## Ключевые находки

### 1. Furniture — проблемная категория
Выручка почти как у Technology (742k против 836k), но прибыль
в 8 раз меньше. Маржа — **2.49%** против 17% у Technology и Office Supplies.

### 2. Central — проблемный регион
Маржа **7.92%** — в 2 раза ниже West (14.94%). При этом выручка выше,
чем у South. Проблема не в объёме продаж, а в их эффективности.

### 3. Central + Furniture = убыток
Единственная убыточная комбинация из 12: **−1.75%**. В других регионах
Furniture хоть и слабая, но в плюсе. Значит, дело в региональной политике.

### 4. Две разные проблемы — разные решения
- **Региональная проблема (скидки в Central):** Appliances, Furnishings,
  Binders. В других регионах те же подкатегории продаются со скидкой
  3–11% и прибыльны.
- **Структурная проблема (подкатегории):** Tables и Machines убыточны
  в 3 из 4 регионов независимо от скидок.

### 5. Бизнес растёт
Выручка +51% (484k → 733k), прибыль +89% (50k → 93k) за 4 года.
Прибыль растёт быстрее выручки — компания становится эффективнее.

### 6. Сильная сезонность
Пики — сентябрь, ноябрь, декабрь. Провалы — январь, февраль.
Разрыв пик/дно — почти 6 раз (ноябрь 352k против февраля 60k).

### 7. Чем меньше сегмент — тем выше маржа
Consumer (54% выручки) — маржа 11.55%. Home Office (19% выручки) —
маржа 14.03% и самый высокий средний чек (240.97).

## Рекомендации

1. **Ограничить максимальную скидку в Central до 15–20%.**
   Критический порог — 20%: выше подкатегория уходит в минус.
   Приоритет — Binders (скидка 51%, убыток −1044).

2. **Пересмотреть ассортимент Tables и Machines.**
   Убыточны в 3 из 4 регионов. Варианты: поднять базовую цену,
   пересмотреть закупку или вывести из ассортимента.

3. **Сконцентрировать маркетинг в сентябре и ноябре–декабре.**
   В январе–феврале — снизить операционные расходы
   (отпуска, обучение).

4. **Развивать сегмент Home Office.**
   Самый маржинальный (14.03%), но самый маленький (909 заказов).
   Потенциал — через программу лояльности для фрилансеров и малого бизнеса.

5. **Провести аудит скидочной политики по всем регионам.**
   Возможно, в West и East тоже есть подкатегории со скидками 30%+,
   которые пока не ушли в минус, но близки к этому.

## Структура ноутбука

| # | Секция | Что делает |
|---|---|---|
| 1 | Загрузка данных | превью «сырых» колонок (разведка), rename в snake_case, парсинг дат, сохранение в SQLite |
| 2 | Обзор данных | диапазон дат, категории, сегменты, регионы |
| 3 | Анализ по категориям | выручка, прибыль, маржа + 2 графика (barh + pie) |
| 4 | Анализ по регионам | маржа по регионам, поиск проблемных |
| 5 | Регион × категория | тепловая карта, ключевая находка (Central × Furniture = −1.75%) |
| 6 | Убыточные подкатегории Central | скидки vs маржа, 7 убыточных подкатегорий из 17 |
| 7 | Сравнение регионов по скидкам | две разные проблемы — региональная и структурная |
| 8 | Динамика по годам | выручка +51%, прибыль +89% за 4 года |
| 9 | Сезонность по месяцам | пики сен/ноя/дек, провалы янв/фев |
| 10 | Сегменты клиентов | чем меньше сегмент — тем выше маржа |

**Визуализации (5 графиков):**
- Маржа по категориям (горизонтальный barh).
- Доли выручки и прибыли по категориям (две pie-диаграммы).
- Тепловая карта «регион × категория» (seaborn heatmap).
- Динамика выручки и прибыли по годам (две линии).
- Сезонность выручки по месяцам (bar с подсветкой пиков/провалов).

Технические детали
Превью CSV (nrows=3) в первой секции — намеренная разведка,
чтобы показать читателю «сырые» названия колонок до переименования
в snake_case. Основной df грузится следующей ячейкой целиком.

SQLite используется для всех агрегатов (GROUP BY, STRFTIME,
оконные функции не нужны). База создаётся при первом запуске ноутбука
из df.to_sql('superstore', ...).

Даты парсятся на этапе read_csv через parse_dates=['Order Date', 'Ship Date'].

Маржа считается как SUM(profit) / SUM(sales) * 100 — не среднее
по строкам, а агрегат по всей группе.

Пороговое значение скидки (~20%) выведено эмпирически из секции 6:
подкатегории со скидкой выше 20% уходят в отрицательную маржу.

## Интерактивный дашборд (Plotly Dash)

Помимо Jupyter-ноутбука, в проекте есть **интерактивный дашборд** на Plotly Dash —
`app.py`. Это веб-приложение, которое позволяет смотреть данные в реальном времени:
выбирать регион, год, категорию — и видеть, как всё пересчитывается.

### Что внутри

**Вкладка «Обзор»:**
- 4 KPI-карточки: выручка, прибыль, маржа, заказы.
- 3 фильтра: год, регион, категория — пересчитывают все графики.
- График динамики выручки и прибыли по годам.
- Круговая диаграмма долей категорий.
- Тепловая карта «регион × категория».

**Вкладка «Проблемы Central»:**
- Scatter-plot: скидка vs маржа по подкатегориям Central.
- Топ-7 убыточных подкатегорий (таблица).
- Свой фильтр года для этой вкладки.

### Как запустить


# Установить зависимости (если ещё не)
pip install -r requirements.txt
pip install dash

# Запустить дашборд
python app.py
